# ADR-0013: The agent surface: typed tools over persistent campaigns

Status: accepted (2026-10, shipped in 0.4.0)

## Context
Campaigns are increasingly operated by language-model agents that write job scripts, submit them to batch schedulers and decide what to run next. An agent can call a Python API, but it works best through tools with declared schemas, it cannot act on a traceback, it retries calls whose outcome it did not see, and its session often ends before the campaign does. Without a dedicated surface, every agent re-implements the campaign loop and its accounting on the fly, and the invariants of ADR-0006 hold only as well as that improvised code.
## Decision
A `cadaques.agent` package exposes campaign operations as a closed registry of tools, each with a JSON-Schema input and output and read-only / destructive annotations. All tools share one response envelope; failures are `ToolError`s from a closed code vocabulary carrying `retryable` and `next_actions`. Campaigns live in a workspace directory and every call rebuilds its campaign from disk (`resume`) and writes it back (`checkpoint`), so no state lives in a server process or an agent session. Mutating calls carry an `actor` and a caller-chosen `request_id`; a repeated request returns its original response. Specs arriving through tools may name only allowlisted participants (shipped, entry-point plugins, or explicitly allowed by the operator), because `CampaignSpec.build` imports arbitrary dotted paths. MCP and a JSON command line are thin front ends over the same registry; `mcp` is an optional extra (ADR-0008).
Rejected alternative: an MCP server with tools defined directly on the Python API through signature introspection. It would tie the contract to one protocol and one SDK, derive schemas from implementation details rather than declaring them, and leave idempotency, attribution and error semantics to each handler.
## Consequences
The tool registry is public interface under ADR-0010: removing a tool, a required argument or an error code is a breaking change. The kernel's invariants are reachable only through the kernel, so agent-written adapters can be checked against the conformance suites rather than trusted. Rebuilding a campaign per call costs a replay of its history; this is negligible next to the evaluations the surface is meant for, and a cache is a later optimization that must not change results.
